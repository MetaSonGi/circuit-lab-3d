# Circuit Lab 3D

three.js로 만든 웹 논리회로 실험실입니다. 설치 없이 브라우저에서 바로 실행되고, 휴대폰에서도 됩니다.
[가상 논리회로 실험실(Unity)](https://metasongi.github.io/virtual-logic-labs/)의 실습 흐름을 가볍고 빠른 웹 3D로 새로 만들었습니다.

🌐 **바로 실행:** https://metasongi.github.io/circuit-lab-3d/

## 할 수 있는 것
| 기능 | 설명 |
|---|---|
| 3D 브레드보드 | 드래그로 회전·이동·확대. 부품은 격자에 맞춰 끌어 옮기기 |
| 부품 | 스위치 · LED · AND · OR · NOT · NAND · NOR · XOR · XNOR |
| 전선 연결 | 출력 핀 → 입력 핀으로 드래그(또는 차례로 클릭). 전선은 3D 곡선으로 놓임 |
| 신호 표시 | 켜진 전선·핀은 네온 초록으로 빛나고 빛 알갱이가 흐름, LED 점등 |
| 진리표 | 스위치 → LED 진리표를 자동으로 계산, 지금 상태 줄 강조 |
| 🎯 미션 8개 | NOT → AND → NAND로 NOT → XOR → 반가산기 → 2:1 MUX → 다수결 → 전가산기 |
| 자동 채점 | 진리표 전체 비교 + 미션별 사용 가능 부품 검사, 통과 시 축하 효과 |
| 저장 | 미션별 회로·진행 상황·자유 실험 회로를 브라우저(localStorage)에 자동 저장 |

## 조작법
- **부품 놓기**: 왼쪽(휴대폰은 아래) 부품 버튼
- **연결**: 핀(●)을 끌어 다른 핀에 놓기 — 출력은 오른쪽, 입력은 왼쪽
- **스위치**: 클릭으로 ON/OFF
- **삭제**: 선택 후 🗑 삭제 또는 <kbd>Delete</kbd>, 전선은 더블클릭
- **카메라**: 빈 곳 드래그 회전, 오른쪽 드래그 이동, 휠·핀치 확대, <kbd>R</kbd> 처음 위치

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 (상단 바, 부품 팔레트, 미션·진리표 패널) |
| `style.css` | 성남 AI 랩 다크 네온 테마, 휴대폰 레이아웃 |
| `app.js` | three.js 장면 · 부품/전선 3D 모델 · 드래그 연결 · 블룸 효과 |
| `sim.js` | 회로 데이터 · 논리 시뮬레이션 · 진리표 · 미션 채점 (DOM 없음) |
| `sim.test.html` | `sim.js` 테스트 11개 — 브라우저로 열면 결과 표시 |

## 로컬 실행
ES 모듈이라 파일을 직접 열지 말고 간단한 서버로 엽니다.

```bash
python -m http.server 8000
```

→ http://localhost:8000 (테스트: http://localhost:8000/sim.test.html)

## 참고
- three.js 0.160 (jsDelivr CDN), 빌드 과정 없는 정적 사이트입니다.
- 순수 조합 회로용입니다. 피드백 루프는 값이 안정되지 않으면 경고만 표시합니다.
